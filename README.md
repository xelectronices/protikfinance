# My Finance — Modern Google Sheets Finance App

This is the responsive GitHub Pages frontend. It connects to the supplied Google Apps Script Web App.

Current UI includes Dashboard, charts, transactions, accounts, assets/liabilities, investments, credit cards, loans/EMIs and bills, with data-entry forms.

Important: the Apps Script backend must expose the corresponding GET/POST actions used by `script.js`. The existing backend currently exposes Income/Expense actions; extend it with the remaining actions before relying on those modules.
